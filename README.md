This program demonstrates an undirected unweighted Graph with developer testing in C++
This program demonstrates the following:;
    1. Adding random nodes and edges to the graph.
    2. Removing random nodes and edges from the graph.
    3. Checking if the graph is cyclic.
    4. Checking if the graph is connected.
    5. Running Dijkstra's Algorithm on the graph.
    6. Running BFS on the graph.
    7. Running DFS on the graph.
    8. Getting the degree of a node in the graph.
    9. Listing all nodes in the graph.
    10. Printing the adjacency matrix of the graph.
    11. Adding a node to the graph.
    12. Adding an edge to the graph.
    13. Removing a node from the graph.
    14. Removing an edge from the graph.
    15. Displaying the graph.
    16. Displaying the degree of a node in the graph.       
    17. Has the ability to add multiple graphs, not employed.
    18. Developer testing.
    This test program only uses one graph and demonstrates all features present in the graph class.
